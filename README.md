# NEET Examination Integrity & Breach Impact Analysis Dashboard

## Overview
An interactive analytical project investigating NEET examination integrity trends, candidate impact, breach severity, and conducting body comparisons using Power BI, Python, SQL, and SQLite.

This repository includes:
- Interactive Power BI dashboard
- Python analytical pipeline
- SQLite forensic database
- SQL-based analytical queries
- HTML analytical summary page
- Visual trend analysis exports

## Key Insights

- Candidate participation increased significantly across examination years.
- Breach severity spikes observed during specific high-impact years.
- Conducting body comparison reveals differences in candidate impact trends.
- Integrity classifications show decline in fully “clean” examination cycles post-2020.

## Resume-Friendly Description

### Examination Integrity & Breach Impact Analysis Dashboard
Built an interactive analytical dashboard processing 20+ years (2006–2026) of examination integrity and breach data, analyzing 6M+ affected candidates and 470+ arrest-related records across multiple conducting bodies. Developed a multi-tool analytics workflow integrating Power BI, Python, SQL, and SQLite for KPI monitoring, comparative breach analysis, integrity classification, and dynamic stakeholder-focused reporting.
